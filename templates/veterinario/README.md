# 🐾 Template Veterinário - Pet Care

Template de landing page profissional para clínicas veterinárias, pet shops e hospitais veterinários.

## 🎨 Design e Cores

### Paleta de Cores
- **Verde Primário**: `#16A34A` - Transmite saúde, natureza e cuidado
- **Verde Claro**: `#22C55E` - Variação suave para destaques
- **Laranja Destaque**: `#F97316` - Energia e carinho
- **Fundo Claro**: `#F9FAFB` - Limpo e profissional

### ✅ Contraste Validado (WCAG AA)
Todas as combinações de cores foram testadas e aprovadas:
- Títulos: 16:1 (Excelente)
- Texto corrido: 10.5:1 (Excelente)
- Texto secundário: 7:1 (Bom)
- Ícones e elementos UI: 4.8:1+ (Aprovado)

## 🚀 Como Usar

1. **Abrir o Live Server na raiz do projeto** (`cosmos-lp-generator`)
2. **Acessar**: `http://127.0.0.1:5500/templates/veterinario/`
3. **Editar**: Modificar `config.js` para personalizar

## 🔧 Personalização

### Informações da Clínica
```javascript
site: {
  title: "Sua Clínica Veterinária",
  name: "Nome da Clínica",
  established: "CRMV-XX XXXXX",
  // ...
}
```

### Contatos
- WhatsApp: Atualizar `whatsappNumber`
- Telefone: Atualizar `contact.phone`
- Endereço: Atualizar seção `address`

### Serviços
Editar array `items` em `card-grid` para incluir seus serviços.

### Imagens
Substituir URLs das imagens do Unsplash por imagens reais da clínica.
