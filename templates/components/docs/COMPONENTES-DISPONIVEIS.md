## 🎯 Como Escolher os Componentes

1. **Identifique o tipo de negócio**: SaaS, serviço local, e-commerce, etc.
2. **Defina as seções necessárias**: Hero, serviços, preços, contato, etc.
3. **Escolha componentes do mesmo estilo**: Mantenha consistência visual
4. **Considere o tema**: Claro ou escuro
5. **Pense na conversão**: Inclua CTAs estratégicos

---

## 📝 Notas Importantes

- Todos os componentes se adaptam automaticamente ao tema claro/escuro
- Componentes inferem cores do tema global quando não há override
- Todos os componentes são responsivos
- Ícones podem usar Lucide Icons ou Font Awesome
- Componentes seguem padrões de acessibilidade (WCAG AA)
